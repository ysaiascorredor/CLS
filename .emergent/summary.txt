<product_requirements>
The goal is to build the CSA Construction Safety Audit, a bilingual (English/Spanish) SaaS platform for the construction industry.

**Core Functionality:**
*   **Dynamic Audits:** Users select specific construction work types to generate a tailored audit checklist.
*   **Team Management:** Subscribers create an organization and invite members. A link-based system is used for invitations, where a unique link is generated to be shared manually.
*   **PDF Reporting:** Generate professional PDF reports of completed audits, including findings, charts, and the subscribing company's logo.

**Commercial and Administrative Features:**
*   **Subscription Model:** Monetization through tiered subscription plans (e.g., Basic, Professional, Enterprise) managed via Stripe. Users can upgrade their plans.
*   **Company Customization:** Organizations can upload their company logo and set their company name, which appears on reports.
*   **Admin Dashboard:** A super-admin panel to view system-wide metrics (total users, revenue), manage users, view system logs, and access support tools.
*   **User Support:** The application must display the owner's contact information (email and phone number) in a support footer visible to all logged-in users.
</product_requirements>

<key_technical_concepts>
- **Tech Stack**: React.js (frontend), FastAPI (Python backend), MongoDB (database).
- **Authentication**: Custom email/password system using JSON Web Tokens (JWT). A global Axios interceptor on the frontend automatically attaches the JWT to API requests.
- **Payments**: Stripe integration for subscription management and checkout sessions.
- **UI/UX**: Frontend built with Shadcn UI components and styled with Tailwind CSS. Charts are implemented using the Recharts library.
- **PDF Generation**: Handled on the backend using the ReportLab and Matplotlib libraries.
</key_technical_concepts>
