<product_requirements>
The goal is to build a comprehensive SaaS application named CSA Construction Safety Audit for performing safety audits in the construction industry.

**Core Functionality:**
*   **Dynamic Audits**: Auditors can select any number of specific construction work types (e.g., Excavation, Height Work). The application must then generate a unique checklist of questions tailored specifically to the selected work types.
*   **Compliance Tracking**: Audit questions require a Yes (compliant) or No (non-compliant) answer.
*   **Issue Documentation**: A No answer must trigger a mandatory form requiring the user to upload a photo, add a comment describing the issue, and detail the corrective action taken.
*   **Bilingual Support**: The entire user interface and all content must be available in both English and Spanish.

**Business & Administrative Features:**
*   **Monetization**: The application must be sold as a subscription service using Stripe, with multiple tiers (e.g., Basic, Professional, Enterprise) that have different limits on audits and team members.
*   **Admin Dashboard**: The app owner requires a super-admin view to monitor key business metrics like total users, active subscribers, revenue, and audit counts.
*   **Team Collaboration**: Subscribers must be able to create an organization, invite team members with specific roles (e.g., Auditor, Observer), and share subscription limits across the team.
*   **Authentication**: User registration and login must be handled via email and password.
</product_requirements>

<key_technical_concepts>
*   **Tech Stack**: React.js (frontend), FastAPI (backend), MongoDB (database).
*   **Authentication**: Email/Password authentication using JWT (JSON Web Tokens) for session management and  for password hashing on the backend.
*   **Payments**: Stripe integration for handling recurring subscription payments.
*   **UI/UX**: Frontend built with Shadcn UI components and styled with Tailwind CSS.
*   **Backend Architecture**: Asynchronous API endpoints using  for non-blocking database operations with MongoDB. Data validation is handled by Pydantic models.
</key_technical_concepts>
