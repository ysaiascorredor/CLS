<product_requirements>
The CSA Construction Safety Audit is a bilingual (English/Spanish) SaaS platform for the construction industry.
**Core Functionality:**
*   **Dynamic Audits:** Users select work types to generate tailored audit checklists. Initially, existing categories were used, with requests to add JSA, JHA (later removed), Safety Daily Plan (later removed), PPE, Lifting Equipment & Cranes, Housekeeping, and Chemical Handling. The latest request is to add an N/A option for audit questions.
*   **Team Management:** Evolved from a link-based invitation system to a direct user creation system (admin provides email/password, user can change it). A remove/delete user functionality was also implemented.
*   **PDF Reporting:** Generate professional PDF reports of completed audits, including findings, charts, and company logos. A Download PDF button was added per audit.
**Commercial and Administrative Features:**
*   **Subscription Model:** Monetization initially through tiered Stripe subscriptions (Basic, Professional, Enterprise). This was simplified to a single CSA Safety Pro unlimited plan (9.99/month). Stripe webhook configuration and proper reflection of subscription status were recurring issues.
*   **Company Customization:** Organizations upload logos and set company names for reports.
*   **Admin Dashboard:** A super-admin panel to view system-wide metrics, manage users, and logs. Access was granted to the user, and previous issues with it being blank due to authentication/connectivity were addressed.
*   **User Support:** Display owner's contact information.
*   **Design Improvement:** Request for a more vibrant, modern UI with attractive colors, better UX, and modern elements (gradients, glassmorphism, animations).
*   **Statistics:** Display percentages for each audit, with progress bars and dynamic colors. The dashboard needs to correctly count all audits.
</product_requirements>

<key_technical_concepts>
-   **Tech Stack**: React.js (frontend), FastAPI (Python backend), MongoDB (database).
-   **Authentication**: Custom email/password system using JSON Web Tokens (JWT).
-   **Payments**: Stripe integration for subscription management, including checkout sessions and webhook processing.
-   **UI/UX**: Shadcn UI, Tailwind CSS, Recharts for charts, and dynamic CSS for design enhancements.
-   **PDF Generation**: ReportLab and Matplotlib on the backend.
</key_technical_concepts>
